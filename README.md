# homebrew-yt-upload

Homebrew tap for [yt-upload](https://github.com/juanjoseluisgarcia/yt-upload),
a CLI that uploads a video to YouTube using the resumable upload protocol.

## Install

```bash
brew tap juanjoseluisgarcia/yt-upload
brew install yt-upload
```

See the [main repo](https://github.com/juanjoseluisgarcia/yt-upload) for setup and usage.
